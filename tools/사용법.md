# PDF → 이미지 추출 도구 사용법

PDF를 깔끔한 이미지로 뽑아주는 도구예요. 스크립트는 `tools/pdf_to_images.py` 하나입니다.

---

## 1. 이 도구가 하는 일

두 가지 방식으로 PDF에서 이미지를 뽑습니다.

- **페이지 렌더 방식 (기본, 고화질)** — PDF의 각 페이지를 통째로 고해상도 이미지로
  그려냅니다. PDF가 내부에서 이미지를 어떻게 저장했든 상관없이 항상 깨끗하게 나와서,
  예전에 겪었던 "이미지가 가로줄(타일)로 잘려 나오는 문제"가 생기지 않습니다.
  → "PDF를 보기 좋은 이미지로" 뽑고 싶을 때는 이걸 쓰면 됩니다.

- **내부 삽입 이미지 추출 방식 (`--mode embedded`)** — PDF 안에 실제로 박혀 있는
  원본 이미지들을 꺼냅니다. 큰 그림이 여러 개의 가로 줄무늬(strip)로 쪼개져 저장된 경우,
  **연속된 같은 폭의 줄무늬를 자동으로 세로로 이어 붙여** 원래 한 장으로 복원해 줍니다.

---

## 2. 빠른 사용법

```bash
# 고화질 페이지 추출 (기본값: 300 DPI, PNG)
python3 tools/pdf_to_images.py 파일.pdf

# 해상도 더 높이기
python3 tools/pdf_to_images.py 파일.pdf --dpi 400

# JPG로 뽑기 (용량 작게)
python3 tools/pdf_to_images.py 파일.pdf --format jpg --quality 95

# 내부 삽입 이미지 추출 (타일 자동 합침)
python3 tools/pdf_to_images.py 파일.pdf --mode embedded
```

주요 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `-o, --outdir` | 결과 저장 폴더 | `<PDF이름>_images` (PDF 옆에 생성) |
| `--mode` | `render`(페이지 렌더) / `embedded`(내부 이미지) | `render` |
| `--dpi` | 렌더 해상도 (render 모드) | `300` |
| `--format` | `png` / `jpg` | `png` |
| `--quality` | JPG 품질 1~100 | `95` |
| `--prefix` | render 모드 파일 이름 접두사 | `page` |

결과 파일 이름: render 모드는 `page_001.png, page_002.png …`,
embedded 모드는 `image_001.jpg, image_002.jpg …` 순서대로 저장됩니다.
끝에 사용한 엔진 / 모드 / 장수 / 폴더 / 파일별 용량 요약이 출력됩니다.

> 참고: 이 도구는 PyMuPDF가 있으면 그걸로 동작하고, 없으면 자동으로
> poppler(`pdftoppm` / `pdfimages`)로 넘어갑니다. 둘 중 하나만 있으면 됩니다.

## 3. 전체 워크플로우 (다음에 이렇게 하면 됨)

- [ ] **a. PDF 업로드** — 채팅창에 PDF를 첨부하고 "이 PDF 고화질로 이미지 추출해줘"
      라고 요청합니다.
- [ ] **b. 추출** — Claude가 `tools/pdf_to_images.py`로 이미지를 뽑습니다.
- [ ] **c. 전달** — 결과를 GitHub 브랜치의 `delivery/` 폴더에 올려서, 다운로드 링크로
      받습니다. (지금은 GitHub 권한이 열려 있어 바로 가능합니다.)
- [ ] **d. 정리** — 파일을 다 받은 뒤 "GitHub에 올린 거 지워줘" 라고 하면,
      브랜치를 원복해서 올렸던 이미지를 삭제합니다.

---

## 4. 전달 방법 메모

이 환경에서 결과 파일을 **손님(사용자) 컴퓨터로 확실하게 보내는 유일한 경로는
GitHub 링크**입니다.

- ✅ GitHub 브랜치에 올려서 다운로드 링크로 전달 — 가능
- ❌ 채팅창에 파일 첨부로 돌려주기 — 현재 불가
- ❌ 구글드라이브 등으로 업로드 — 현재 불가

그래서 결과물은 항상 GitHub `delivery/` 폴더에 올려 링크로 받는 방식을 씁니다.
